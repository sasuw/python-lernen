# Kleine Programme zum Ausprobieren

Die Beispiele passen zur [Thonny-Anleitung](../docs/anleitungen/python-thonny-getting-started.md).
Alle laufen mit der Python-Standardbibliothek; zusätzliche Pakete sind nicht nötig.

| Datei                                  | Ergebnis                                    | Eine mögliche Änderung                                    |
| -------------------------------------- | ------------------------------------------- | --------------------------------------------------------- |
| [01_hallo.py](01_hallo.py)             | Zwei Nachrichten in der Shell.              | Eine dritte Nachricht ergänzen.                           |
| [02_begruessung.py](02_begruessung.py) | Eine Begrüßung mit eingegebenem Namen.      | Nach dem Lieblingsspiel fragen.                           |
| [03_zahlenraten.py](03_zahlenraten.py) | Ein Spiel mit einer Zahl zwischen 1 und 20. | Den Zahlenbereich vergrößern und den Ansagetext anpassen. |
| [04_zeichnen.py](04_zeichnen.py)       | Ein Quadrat in einem eigenen Fenster.       | Eine andere Farbe oder ein Dreieck zeichnen.              |

In Thonny eine Datei öffnen und **F5** drücken. Eingaben gehören in die Shell
und werden mit Enter bestätigt. Beim Zahlenraten sind zunächst nur ganze Zahlen
vorgesehen; die [Fehlerhilfe](../docs/nachschlagen/fehlerhilfe.md) erklärt andere Eingaben.
Das Zeichenfenster bleibt offen, bis es geschlossen wird.

Eigene Varianten über **Speichern unter…** nach `spielwiese/` oder `uebungen/`
kopieren. So bleiben die Ausgangsbeispiele zum Vergleichen erhalten.
