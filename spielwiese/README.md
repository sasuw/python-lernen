# Spielwiese

Hier dürfen halbfertige Ideen und kleine Experimente liegen. Es gibt keine
vorgegebene Reihenfolge und keine Bewertung.

Die Datei [experiment.py](experiment.py) lässt sich direkt in Thonny öffnen und
mit **F5** starten. Danach etwa eine Zahl verändern, eine Ausgabe ergänzen oder
unter einem neuen Namen ein ganz anderes Experiment speichern.

Auch Kopien aus [beispiele/](../beispiele/README.md) passen hierher. Ein Versuch
darf scheitern: Die [Fehlerhilfe](../docs/nachschlagen/fehlerhilfe.md) hilft beim
Verstehen. Eine größere Idee bekommt später einen eigenen Ordner unter
[projekte/](../projekte/README.md).
