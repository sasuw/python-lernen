# Eigene Projekte

Hier ist Platz für Programme, die über eine einzelne Übung hinausgehen.
Ein kleines funktionierendes Spiel ist ein guter Anfang; Extras können später
dazukommen.

| Idee                  | Erste spielbare Version                       | Möglicher Ausbau                           |
| --------------------- | --------------------------------------------- | ------------------------------------------ |
| Schere, Stein, Papier | Eine Runde gegen eine zufällige Computerwahl. | Mehrere Runden und eine Punkteanzeige.     |
| Quiz                  | Drei feste Fragen und eine Punktzahl.         | Fragen und Antworten in Listen sammeln.    |
| Textabenteuer         | Zwei Räume und eine Entscheidung pro Raum.    | Funktionen für Räume, später ein Inventar. |
| Turtle-Kunst          | Eine Form mehrfach zeichnen.                  | Farben, Größen und Drehrichtung variieren. |

## Ein Projekt anlegen

1. Einen Unterordner wie `mein_quiz` anlegen.
2. In Thonny eine Datei `main.py` in diesem Unterordner speichern.
3. In einer kleinen `README.md` oder einer Textdatei festhalten: Was macht das
   Programm? Wie startet es? Welche Idee fehlt noch?
4. Zunächst die kleinste Version bauen, die schon ausprobiert werden kann.

Zum Starten `main.py` in Thonny öffnen und **F5** drücken. Für mehrere eigene
Funktionen oder eine Liste hilft der [Spickzettel](../docs/nachschlagen/python_spickzettel.md).
